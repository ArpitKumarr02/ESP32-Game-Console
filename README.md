ESP32 CRT Arcade

A simple retro gaming console built using an ESP32 and a CRT television.

The project uses composite video output to display a gaming interface and run games on an old CRT TV.

Features

- ESP32-based gaming console
- Composite video output
- CRT TV support
- On-screen game menu
- Multiple playable games
- RGB332 colour format
- NTSC/PAL support

Hardware

- ESP32 NodeMCU-32S
- CRT television with AV input
- Push buttons
- Connecting wires

Software

- Arduino IDE
- ESP_8_BIT_GFX library
- C++ / Arduino
